# References

Bibliography for `Protocol.md`. Entries are sorted alphabetically by first-author surname. Citations in the protocol use the `[Author, Year]` form; here each entry gives the full reference, the publication venue, and a stable identifier (arXiv ID or DOI) where available.

**Important note for thesis use.** This bibliography was compiled from the practical-work session and reflects what was referenced during the project. Before using any of these in a formal thesis citation, you should verify each entry against the publisher's record (Google Scholar, the venue's official proceedings page, or the arXiv abstract page) for the canonical author list, page numbers, and DOI. Conference proceedings are particularly likely to change page numbers between preprint and final publication. A few entries below are flagged where the exact metadata should be double-checked.

## How to use this file in a thesis

When citing in the thesis itself, replace the human-readable `[Author, Year]` keys in `Protocol.md` with whatever citation style your institution requires (BibTeX, IEEE numbered, APA, etc.). The two `⚠️ verify` flags (BBDM and CPDM) mark entries whose exact metadata should be re-confirmed against the official proceedings page before final submission — neither was double-checked against the publisher's record during the practical work.

A reasonable next step is to import this bibliography into a reference manager (Zotero, Mendeley, JabRef) by manually entering each one or by importing the arXiv / DOI identifiers, so the formal thesis can pull consistent BibTeX entries.
